Relations are canonical governed records with immutable endpoint/type identities, exact type-version pins, typed values, owner, lifecycle, half-open business validity and asserted provenance. A source scan cannot replace curator intent. Source status and governed lifecycle have separate meanings. Imported and derived claims need their own required future implementations; a manual graph does not establish technical lineage.

Nominal endpoint rules match immutable authored asset-type UUIDs and each endpoint's actual pinned ancestry. Complete logical-type adjacency enforces structural maxima and optional acyclicity across all live pins and dates. Positive minima need persistent participation bindings for zero-edge assets, so this increment rejects them explicitly. Compatible publication preserves pins; destructive or structural policy changes with live edges require an explicit future relation migration. Ordinary endpoint assignment/state changes and complete mixed-version type migrations validate the entire proposed endpoint set before writing.

The tenant ledger serializes canonical graph changes. Application locks expand the incident asset union before acquiring ordered row locks and principal locks. A volatile statement guard uses a nonblocking ledger acquisition for direct SQL, avoiding ledger/row lock inversion; an internal bigint graph fence also causes stale repeatable-read writes to fail. Deferred checks validate complete final constraints and require matching immutable revisions plus paired audit/outbox. Derived endpoint/ACL projections are immutable and parent-validated. Runtime roles cannot write the graph counter or bypass forced tenant RLS.

Graph traversal filters current actor, edge and both endpoint access before every hop, count and bound. Hidden bridges cannot connect visible assets. Each page recomputes a bounded coherent traversal. A domain-separated HMAC binds the exact internal bigint, actor, tenant, root and resolved filters; signed cursors expose only the opaque fence. The default first-page validity instant may be echoed or recovered from the cursor. Identity/member revocation is rechecked independently of that fence. Any asset revision conservatively invalidates graph and relation-list pages because those views include current endpoint metadata.

Audit authorization distinguishes asset and relation action namespaces even when their UUIDs coincide. An integrity check over an inaccessible audit chain returns a generic scope error without counts or hashes; filtering hidden events and claiming the remaining chain is complete would be misleading. Type-level events contain only definition/version evidence. Failed relation mutation audit records contain sanitized codes; canonical failures never leave success receipts.

The profile bounds mutations to1,000 live edges/2,000 assets/512KiB and traversal to1,000 authorized nodes/5,000 edges/512KiB, with explicit refusal rather than truncation. Graphs use React Flow under MIT with an accessible equivalent table. This synchronous profile is not a large-graph, historical reconstruction, minimum participation, relation-migration or production-restoration qualification.
