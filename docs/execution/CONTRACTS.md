# M1 shared contracts (2026-11-15)

Lead owns API, DB migration, shared schemas and integration. Web agent owns apps/web and packages/ui/config; runtime agent owns deploy/compose, dev, apps/workflow-worker, apps/site-runner and python; register agent owns requirements and generated views.

HTTP origin http://localhost:4310; Keycloak browser issuer http://localhost:4311/realms/governance; container identity transport http://keycloak:8080 but canonical issuer must remain identical. API port 4310, serves built web via static plugin. Vite proxy /api,/auth in dev. JSON API /api/v1, camelCase resources, errors application/problem+json {status,title,detail,code,correlationId}.

GET /api/v1/me -> {user:{id,name},tenants:[{id,name,role}],tenant:{id,name,role},permissions:string[],csrfToken:string}. Unauthenticated 401. GET /auth/login begins OIDC; GET /auth/callback; POST /auth/logout (CSRF). Tenant switch POST /api/v1/session/tenant {tenantId}, server validates membership. Mutations send X-CSRF-Token from me; source creation/scan Idempotency-Key; asset edits If-Match numeric version.

GET /api/v1/assets?q=&type=&cursor=&limit= -> {items:Asset[],total:number,nextCursor:string|null,facets:{type:string,count:number}[]}; search must use OpenSearch with canonical authorization. Asset {id,name,qualifiedName,type,description,ownerId,ownerName,sourceId,sourceName,version,observedAt,updatedAt,status,metadata}. GET /assets/:id -> {asset,columns:Asset[],audit:Audit[]}. PATCH /assets/:id {description?,ownerId?} -> {asset}. GET /api/v1/members -> {items:[{id,name,role}]}. GET /api/v1/audit -> {items:Audit[]} Audit {id,action,resourceId,actorName,occurredAt,changes,hash,previousHash}.

GET /api/v1/sources -> {items:Source[]}; POST /sources {name,host:"source-postgres",port:5432,database:"harbor",schema:"public",secretRef:"demo-postgres"} -> {source}. Source {id,name,host,port,database,schema,secretRef,status,lastSuccessfulScan,capabilities}. POST /sources/:id/scans {} -> 202 {job:Job}. GET /api/v1/jobs -> {items:Job[]}; GET /jobs/:id -> {job}. Job {id,sourceId,status,createdAt,finishedAt,assetCount,errorCode}; status queued/running/succeeded/failed/cancelled. GET /api/v1/overview -> {assetCount,sourceCount,ownedCount,jobCount,recentAudit:Audit[]}. GET /api/v1/capabilities -> honest implemented subset/status. No empty decorative routes for unimplemented product areas.

Worker API (server-to-server, separate SITE_TOKEN; header Authorization: Bearer, X-Tenant-Id validated against SITE_TENANTS): GET /internal/jobs/pending -> {items:[{id,tenantId,sourceId}]}; POST /internal/jobs/:id/claim -> {job,source}; POST /internal/jobs/:id/complete {observedAt,sourceVersion,permissionFingerprint,records:[{externalId,name,qualifiedName,type,parentExternalId?,metadata}],complete:true} -> {job}; POST /internal/jobs/:id/fail {code} -> {job}. Job identity uniquely includes tenant; actor fixed to authorized site. Claim retry returns same job for replay. Completion idempotent; no raw credentials in payloads. Root implements endpoints.

Runtime dispatcher polls pending, starts Temporal workflow scanSourceWorkflow({tenantId,jobId}) id `scan:{tenantId}:{jobId}` on gc-workflow. Workflow activity executeScan on gc-site passes IDs only; site claims job from API, invokes the isolated uv Python worker with scoped source parameters; only the Python worker resolves secretRef from its local generated secret file. Python produces bounded metadata records, OID identities. Runtime agent may propose changes via messages, not independently change these contracts.

Secrets generated under ignored .local, chmod 0700/0600. DATABASE_URL runtime gc_app; MIGRATION_DATABASE_URL privileged owner only migrator. Database service postgres, db governance. Root migration script invoked `pnpm db:migrate`, seed `pnpm db:seed`. Source initialization owned runtime agent. App build/root package owned lead, use root node_modules and tsx for Node processes initially. Root image command pnpm api/start or pnpm workflow/start or pnpm site/start. Runtime agent must coordinate exact entrypoint scripts.
